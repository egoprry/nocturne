Privacy model

Nocturne performs color analysis inside the page, stores preferences with Chromium extension storage, and makes no fetch, analytics, telemetry, account, or reporting requests. “Broken site” actions are local records only. Imported custom CSS is treated as code you supplied and is never downloaded from a community server.
